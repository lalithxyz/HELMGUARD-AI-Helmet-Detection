# HELMGUARD – Project Details

## Project Description

HELMGUARD is an AI-based helmet detection and vehicle safety system designed to improve two-wheeler rider safety. The system uses computer vision and a trained YOLO deep learning model to detect whether a rider is wearing a helmet.

## Duration

2nd Year – Final Year

## Domain

Artificial Intelligence, Computer Vision & IoT

## Tech Stack

- Python
- YOLO
- Ultralytics
- OpenCV
- Deep Learning
- Computer Vision
- Arduino / Microcontroller

## Team Size

3

## Complexity

Intermediate to Advanced

## Role & Contributions

- Dataset preparation and image preprocessing
- Model training and testing
- Helmet detection implementation
- Integration of the trained model with OpenCV
- Development of the real-time detection pipeline
- Designed the logic for helmet-based vehicle ignition control

## Key Outcome

Developed an AI-based prototype capable of detecting helmet usage and demonstrating how helmet detection can be integrated with vehicle ignition control to improve two-wheeler rider safety.
